# MS900 Microsoft-365-admin

Comecei a solucionar o challenge implementada pela #learnit na Microsoft 365 admin

ambiente do Microsoft 365 admin é a interface centralizada para gerenciar todos os aspectos do seu locatário do Microsoft 365. É um portal web que permite aos administradores configurar, gerenciar e monitorar os serviços do Microsoft 365, incluindo Office 365, Azure Active Directory, SharePoint, Exchange, Teams e muitos outros.

   
*Este repositório documenta a uma infraestrutura de colaboração e produtividade  no ecossistema Microsoft 365 para* :

## Objetivos do desafio
O objetivo principal foi a configuração gestão em um ambiente organizacional seguro e escalável, abrangendo desde já a gestão de identidades até o ciclo de vida dos colaboradores.

## Desafios a implementar 

Gestão de utilizadores: Criação e configuração de usuários na  estrutura organizacional.

**Gestão de Grupos**: criação de Grupos de Segurança e Listas de Distribuição para os departamentos de Marketing e Finanças.

**Colaboração e Acesso**: Atribuição estratégica de membros a grupos para facilitar a partilha de recursos.
**Licenciamento Escalável**: Configuração de licenciamento baseado em grupos de segurança, otimizando a gestão de subscrições.

**Gestão de Ciclo de Vida**: configurações de segurança para suspender acessos e eliminação de usuários.

## Estrutura do Repositório
O repositório está estruturado da seguinte forma:

**/desafio-01/: Criação de Utilizadores.**
**/desafio-03/: Criação de Grupos.**
**/desafio-04/: administrar de Membros.**
**/desafio-05/: Licenciamento por Grupo.**
**/desafio-06/: Gestão do Ciclo de Vida.**
