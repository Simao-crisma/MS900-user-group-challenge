# Desafio 3 – Criação de Grupos
Este diretório contém as evidências da configuração e criação dos grupos organizacionais no Microsoft 365.

  *A criaçao de grupos, é necessario ir ate ao menu,na opção equipes e grupos clique em equipes e grupos ativos,clicando no tipo de grupo preciso,
ir no campo adicionar o grupo(qual seja o tipo escolhido), ptreencher o campo das  informações basicas,proprietarios,Menbros, as definições e concluir*.

## Grupos criados Configurados

**GRP-Marketing-LearnIT** (Tipo: Microsoft 365): Destinado à colaboração da equipa de marketing, permitindo o uso partilhado de ficheiros, calendário e integração com o Microsoft Teams.

**SG-Finance-LearnIT** (Tipo: Segurança): Criado especificamente para a gestão de permissões e segurança de dados do departamento financeiro.
